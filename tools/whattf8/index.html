WhatTF8

Check a file or URL for character encoding issues, preview decoded text, and export a UTF-8 copy. Your files are processed locally in your browser.

Local files are not uploaded to a server. URL inspection requires the remote website to permit cross-origin access (CORS). Character detection is heuristic; verify the preview before converting.

3. Convert and download
Converts decoded text to a UTF-8 file, without a byte-order mark. The source file remains unchanged. Review the preview before downloading.




Guidance and limitations
Use UTF-8 for interoperable plain-text data such as CSV, JSON, XML, and HTML. The encoding of a webpage's text is not necessarily the encoding of files linked from it. Binary formats such as PDF, DOC, and DOCX cannot be made UTF-8 by simply changing their bytes; conversion requires document-aware software. This tool does not preserve formatting from those formats.
